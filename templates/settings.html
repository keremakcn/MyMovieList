Don't have a token yet?

  1. Create a free TMDB account: themoviedb.org/signup
  2. Go to your account API settings and request an API key (choose "Developer").
  3. Copy the "API Read Access Token" (a long string, not the short API key) and paste it above.

Your token is stored only in your browser's session cookie — it is never saved to the app's database.
